
# 元智大學失物招領網站
Lost & Found YZU

## 專案介紹
本專案以元智大學校園為背景，設計一個整合失物通報、拾獲登記及失物搜尋的網站，希望讓校園中的失物資訊更容易被查找與管理。

## 主要功能
- 首頁：提供 Found、Lost、Search 三個主要功能入口。
- 如何找東西：提供尋找遺失物的步驟。
- 找失物：提供遺失物品表單。
- 撿到失物：提供拾獲物品表單。
- 搜尋：提供物品搜尋與分類篩選介面。
- 失物統計：以長條圖及圓餅圖呈現統計資料。
- 網站設計思路：介紹專題的製作動機與設計理念。

## 使用技術
- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome

## 設計特色
- 黃色與黑色作為主要視覺配色。
- 使用圓形按鈕呈現首頁主要功能。
- 側邊滑動式導覽選單。
- 表單與商品卡片式搜尋介面。
- 支援不同螢幕尺寸的響應式排版。

## 專案限制
本專案目前為前端課程展示版本，尚未串接後端及資料庫。表單資料不會實際儲存，搜尋與統計使用展示資料。

## 開發目的
透過本專題實際練習 HTML、CSS 與 JavaScript，將課堂所學應用於校園生活情境，並累積網頁設計與前端開發經驗。
